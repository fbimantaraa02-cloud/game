Susun bagian-bagian HTML dari awal!

Petunjuk: pilih deklarasi dokumen dahulu, lalu bagian luar, kepala, dan isi.

Jika aturan ini diterapkan pada judul, bagaimana warnanya?

h1 { color: blue; }

Apa yang terjadi pada paragraf dengan aturan ini?

p { text-align: center; }

Bagaimana ukuran huruf teks dengan aturan berikut?

body { font-size: 20px; }

Apa hasil dari kode CSS berikut?

div { background-color: yellow; }
